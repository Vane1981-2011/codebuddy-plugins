组合高级 UI、电影级动效、AI 素材与转化文案，完成落地页、营销站、产品页和数据看板。

## 什么时候用它

前端页面容易模板化，视觉、动效、素材和文案彼此割裂。

**适合**：需要把这类判断从“凭经验”变成“有输入、有步骤、有交付物”的工作。  

## 不适用

替代品牌策略或未经授权的素材使用。

## 30 秒安装

```text
/plugin marketplace add Vane1981-2011/codebuddy-plugins
/plugin install frontend-dev
```

安装后直接描述任务，或显式调用 `/frontend-dev`。

## 输入与输出

| 项目 | 内容 |
|---|---|
| 最小输入 | 产品目标、受众、品牌约束、内容素材与技术栈 |
| 主要输出 | 可运行页面、响应式样式、动效、媒体资产与交付说明 |
| 交付形态 | 结构化结论、执行记录与可复用模板 |

## 执行流程

1. **明确页面目标与视觉方向**
2. **建立信息架构和组件层级**
3. **实现视觉、响应式和动效**
4. **补齐素材与文案**
5. **做可访问性、性能和回归检查**

## 使用示例

```text
为一款财务 SaaS 制作高完成度的产品落地页。
```

## 它会交付什么

- 一份可以直接进入下一步工作的结构化结果，而不是泛泛建议。
- 关键假设、证据来源和未决问题会被显式记录。
- 涉及专业判断时，输出会标注适用边界，需由具备资质的人复核。

## 质量与边界

- 执行前确认目标、约束与最小输入，信息不足时先补关键事实。
- 关键结论保留来源、假设和验收记录，避免“看起来合理”的黑箱输出。
- 涉及法律、税务、投资、安全等专业判断时，本技能只作为辅助材料，不替代持证专业人士的意见。
