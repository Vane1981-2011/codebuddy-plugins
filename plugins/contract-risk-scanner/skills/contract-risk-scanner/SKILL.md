# Contract Risk Scanner — 合同风险扫描AI助手

## 目的

端到端自动化合同风险扫描：从合同文件读取 → 条款提取 → 6类风险逐条扫描 → 立场加权重评估 → 双格式报告生成，一句自然语言即可触发完整工作流。

## 触发条件

当用户请求以下任何场景时激活：

- "扫描这份合同的风险"
- "帮我审查这份合同"
- "审一下这个合同有没有陷阱条款"
- "分析合同条款风险"
- "contract risk scan"
- "合同风险评估"

## 核心理念

**认识 → 模仿 → 创新 → 超越**

从合同文本的结构化理解出发，复刻专业法务的审查逻辑，注入行业参数和跨域联动，最终实现超越人类审查精度和速度的智能助手。

## PnP 完整执行管线

```
合同文件(.docx/.pdf) + 己方角色
    │
    ├── PnP-0: 条款提取 ──→ 结构化条款列表
    │
    ├── PnP-1: 6类风险扫描 ──→ 可疑条款(风险类型+等级)
    │
    ├── PnP-2: 立场加权评估 ──→ 调整后风险清单(含视角说明)
    │
    ├── PnP-3: 生成Excel报告 ──→ 合同风险扫描报告_{合同名}.xlsx
    │
    └── PnP-4: 生成谈判备忘 ──→ 合同修改建议备忘_{合同名}.md
```

## 执行阶段详解

### PnP-0：合同条款提取

**目标**：从合同文件中提取结构化条款信息，不进行风险分析。

**提取内容**：
- 合同标题、签约双方名称、签署日期、合同金额
- 完整的条款列表（逐条提取：编号 + 标题 + 正文）
- 合同总页数、条款总数

**执行步骤**：
1. 识别输入文件格式（.docx → 使用python-docx，.pdf → 使用pymupdf/fitz）
2. 提取全部文本内容
3. 解析条款结构：识别编号模式（第X条/X./X.X/一、二、三 等）
4. 输出结构化条款列表

**失败处理**：
- 文件加密 → 标注 `无法提取（文件密码保护）`
- 扫描件无文字层 → 标注 `无法提取（不可读取文字）`
- 格式不支持 → 标注 `文件 xxx.doc 格式不支持，请提供 .docx 或 .pdf`
- 无条款结构 → 降级为段落模式分析，标注 `合同缺少编号条款结构，已按段落模式分析`

### PnP-1：6类风险逐条扫描

基于PnP-0提取的条款列表，逐条匹配6大类风险特征库。每条输出：条款原文、风险类型、风险等级（高/中/低）。

#### Type 1：无限责任 / 赔偿责任不对等

**扫描规则**：
| 触发条件 | 低风险 | 中风险 | 高风险 |
|---------|--------|--------|--------|
| 责任表述关键词 | 含"赔偿损失" | 含"全部损失""一切后果" | 含"无限责任""连带无限" |
| 赔偿上限（相对合同额） | 明确上限 ≤ 1x | 上限 1.5-3x 或无明确表述 | 上限 > 3x 或无上限 |
| 责任对等性 | 双方对等 | 己方责任范围更广 | 己方无上限而对方有上限 |
| 间接损失承担 | 双方均不承担 | 仅己方承担间接损失 | 己方承担间接损失且无上限 |

**典型高风险句式**：
- "乙方对因其原因造成的全部损失承担无限赔偿责任"
- "无论何种原因，乙方应赔偿甲方因此遭受的一切损失"
- "甲方的赔偿责任在任何情况下不超过合同金额；乙方的赔偿责任不受此限"

#### Type 2：单方解除权

**扫描规则**：
| 触发条件 | 低风险 | 中风险 | 高风险 |
|---------|--------|--------|--------|
| 解约权利 | 双方均可解约 | 对方可"随时"解除 | 对方可"无条件""单方"解除 |
| 通知期限 | 双方一致 | 己方 ≥ 90天 / 对方 ≤ 15天 | 己方须书面通知/对方无需通知 |
| 解约后果 | 按实际结算 | 赔偿标准不明确 | 对方解约后不承担任何责任 |
| 续约条款 | 双方均有选择权 | 对方享优先续约权 | 续约条件完全由对方单方决定 |

**典型高风险句式**：
- "甲方有权随时单方解除本合同，无需说明理由"
- "甲方解除合同的通知到达乙方时即生效，乙方不得提出异议"
- "甲方提前7日通知即可解除；乙方需提前90日书面申请并经甲方同意"

#### Type 3：交付 / 验收标准模糊

**扫描规则**：
| 触发条件 | 低风险 | 中风险 | 高风险 |
|---------|--------|--------|--------|
| 验收标准 | 有具体量化指标 | 含"满意为止""符合行业标准"等主观表述 | 无任何明确验收标准 |
| 验收期限 | ≤ 15天 | 16-30天 | > 30天或无期限 |
| 修改次数上限 | ≤ 2次 | 3次 | 无限制/"无限次" |
| 验收不通过后果 | 明确修正流程 | 责任划分不清 | 可单方解除 + 索赔 |

**典型高风险句式**：
- "以甲方满意为最终验收标准"
- "乙方应按照甲方的要求进行修改，直至甲方满意为止"
- "验收期限由甲方根据实际情况确定"

#### Type 4：付款条款不利

**扫描规则**：
| 触发条件 | 低风险 | 中风险 | 高风险 |
|---------|--------|--------|--------|
| 付款节点 | 与交付里程碑挂钩 | 付款节点由对方单方控制 | "验收合格后60日内"等长周期 |
| 质保金比例 | ≤ 3% | 3%-5% | > 10%（建安）/ > 5%（其他） |
| 质保期限 | ≤ 1年 | 1-2年 | > 2年 |
| 逾期付款违约金 | ≥ 日万分之五 | 存在但标准偏低 | 无逾期付款违约金条款 |
| 付款前置条件 | 1-2个客观条件 | 多重前置条件 | 含对方主观判断的前置条件 |

**典型高风险句式**：
- "甲方在验收合格后90日内支付合同款项"
- "质保金为合同总额的15%，质保期三年"
- "付款时间由甲方根据资金情况合理安排"

#### Type 5：知识产权归属不清

**扫描规则**：
| 触发条件 | 低风险 | 中风险 | 高风险 |
|---------|--------|--------|--------|
| 成果IP归属 | 双方共有 / 按约分配 | 成果默认归对方 | 成果归对方 + 己方需"无偿""永久""不可撤销"授权 |
| 背景IP处理 | 各自保留 | 背景IP被要求授权使用 | 背景IP被要求"永久""不可撤销""免费"授权 |
| 侵权免责 | 有相互免责条款 | 免责条款不完整 | 无侵权免责，或由己方承担全部侵权责任 |
| 后续使用限制 | 双方均可合理使用 | 己方后续使用需经同意 | 己方在项目结束后不得使用任何成果 |

**典型高风险句式**：
- "本项目所产生的全部知识产权归甲方所有"
- "乙方应将背景技术永久、不可撤销、免费地授权给甲方使用"
- "因知识产权侵权所产生的一切责任由乙方独立承担"

#### Type 6：管辖 / 争议解决不利

**扫描规则**：
| 触发条件 | 低风险 | 中风险 | 高风险 |
|---------|--------|--------|--------|
| 管辖约定 | 己方所在地 | 项目所在地/中立 | 对方所在地法院/仲裁 |
| 仲裁费用承担 | 各自预交 | 按比例分担 | "败诉方承担"且胜诉可能性低 |
| 不可抗力条款 | 范围合理 | 范围偏窄 | 无不可抗力条款 |
| 适用法律 | 中国大陆法律 | — | 约定不熟悉的境外法律 |

**典型高风险句式**：
- "因本合同引起的争议，由甲方所在地人民法院管辖"
- "仲裁费、律师费、差旅费等全部费用由败诉方承担"
- "本合同适用XX国法律"（非中国大陆）

### PnP-2：立场视角加权

根据用户角色动态调整6类风险权重，使风险等级更贴合实际谈判立场。

**立场权重矩阵**：
| 角色 | Type1 无限责任 | Type2 单方解约 | Type3 验收模糊 | Type4 付款不利 | Type5 IP不清 | Type6 管辖不利 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 甲方/采购方 | 25% | 15% | **25%** | 10% | 15% | 10% |
| 乙方/供应方 | 20% | 10% | 10% | **30%** | **20%** | 10% |
| 出租方 | 15% | **30%** | 10% | 20% | 10% | 15% |
| 承租方 | **30%** | 20% | 15% | 10% | 10% | 15% |
| 合作方(技术) | 10% | 10% | 10% | 15% | **35%** | 20% |
| 用人单位 | 15% | 15% | 0% | 20% | **35%** | 15% |

**加权公式**：
```
加权分 = Σ(类型原始风险分 × 立场权重)
其中：高风险=3分，中风险=2分，低风险=1分
重新定级：加权分 ≥ 2.5 → 高风险；2.0 ≤ 加权分 < 2.5 → 中风险；加权分 < 2.0 → 低风险
```

## 输出格式

### 输出1：合同风险扫描报告_{合同名}.xlsx

**Sheet1：风险总览**
| 列 | 内容 |
|----|------|
| A | 合同名称 |
| B | 签约双方 |
| C | 合同金额 |
| D | 高风险条款数 |
| E | 中风险条款数 |
| F | 低风险条款数 |
| G | 综合风险评级（A/B/C/D） |
| H | 是否建议签署 |

**综合评级规则**：
- **A级**：高风险=0 且 中风险 ≤ 2 → "建议签署"
- **B级**：高风险=0 且 中风险 > 2 → "建议签署，关注中风险条款"
- **C级**：高风险 ≤ 3 → "有条件签署，必须修改高风险条款"
- **D级**：高风险 > 3 或存在底线条款 → "不建议签署"

**条件格式**：高风险行=红色(#C23350)、中风险行=黄色(#E6A817)、低风险行=绿色(#2E8B57)
**格式要求**：第一行冻结，所有列支持筛选

**Sheet2：风险条款明细**
列：条款编号 | 条款标题 | 条款原文（关键句）| 风险类型 | 风险描述 | 风险等级 | 对己方影响（财务/法律/运营）| 修改建议 | 谈判优先级（必须修改/建议修改/可接受）

兜底行：无风险条款时显示"未发现高风险条款，建议仔细核对合同整体合理性"

**Sheet3：修改对照表**
列：编号 | 原文（完整条款）| 建议修改后文本 | 修改理由 | 法律依据（如有）

## 技能集成

### 与 tax-risk-early-warning-engine 联动
当合同涉及金额较大（>50万元）或包含税务条款时，自动建议联动税务风险预警引擎，输出合同涉税条款风险清单。

### 与 financial-bp-command-center 联动
当合同风险条款涉及财务敞口时（如无限责任条款），调用业财融合工具量化潜在财务影响。

### 与 quality-assessment-expert-system 联动
重大合同（标的 > 100万元 或 D级风险）自动建议启动三专家四轮迭代评估。

## 错误处理矩阵

| 错误场景 | 处理方式 | 用户提示 |
|---------|---------|---------|
| 文件格式不支持 | 跳过，列文件名+原因 | "文件 xxx.doc 格式不支持，请提供 .docx 或 .pdf 格式" |
| 文件密码保护 | 跳过，标注原因 | "文件已加密（密码保护），无法提取内容" |
| 扫描件无文字层 | 尝试OCR，失败则跳过 | "扫描件无文字层且OCR识别失败，请提供可搜索PDF或Word文件" |
| 合同无条款结构 | 全文分析，降级为段落模式 | "合同缺少编号条款结构，已切换为段落模式分析，建议人工复核" |
| 无任何风险条款 | 生成正常报告，零风险标注 | "未发现6大类风险条款，建议仔细核对合同整体合理性和行业特殊风险" |
| Excel生成失败 | 回退至CSV格式 | "Excel报告生成失败，已生成CSV替代文件，可手动导入Excel" |
| 文件过大（>50MB） | 提示超限，建议分割 | "文件过大（{size}MB），建议仅提取核心条款章节进行扫描" |
