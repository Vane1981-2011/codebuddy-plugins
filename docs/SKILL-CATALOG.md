## 快速选择

- **上下文管理器**（`context-manager`，元技能与智能体）— 让下一次对话记得这一次的结论。在对话开始加载项目上下文，在结束前沉淀进展、决策与待办，避免重复解释和上下文断层。
- **专家市场同步器**（`expert-sync`，元技能与智能体）— 让能力库跟着专家市场持续更新。检测专家与技能市场的新增和更新，按领域相关性匹配，输出可审计的安装与升级建议。
- **第一性原理推理**（`first-principles-reasoning`，元技能与智能体）— 把复杂问题拆到不可再拆的事实。以准备、执行、质检、复盘四阶段闭环组织推理，结合三层推理体系与工程化交付检查。
- **上下文学习机制**（`in-context-learning`，元技能与智能体）— 管理注意力预算，而不是堆更多提示词。解释并应用上下文内学习、注意力分配、遗忘边界与探索—利用策略，优化复杂任务的上下文组织。
- **稽影 · 多智能体信任基础设施**（`jiying`，元技能与智能体）— 让多智能体的每一步都可追溯、可拦截。六智能体编排与宪法即代码，结合 TEP 可信执行协议、七项质量门禁和十类认知偏见交叉验证。
- **MAD 深度推理管线**（`mad-think-pipeline`，元技能与智能体）— 把复杂判断拆成可交叉验证的并行路径。以 S1–S4 管线完成问题分解、并行推理、交叉验证与综合，适合架构决策和根因诊断。
- **技能智能中枢**（`skill-intelligence`，元技能与智能体）— 从「找技能」升级为「管理能力资产」。联合搜索多个技能市场，按场景匹配评分，并检查冗余、冲突、质量与生命周期。
- **财务 BP 指挥中心**（`financial-bp-command-center`，商业与金融）— 把业财融合方法变成可计算的经营工具。覆盖四讲二十二模块与八个工具模型，从量本利、客户盈利到预算监控和投资可行性。
- **税务风险预警引擎**（`tax-risk-early-warning-engine`，商业与金融）— 用指标和阈值把税务风险前置。覆盖发票、特殊业务、收入、成本费用四类十五项指标，提供三区阈值、建安参数与风险解释。
- **合同风险扫描器**（`contract-risk-scanner`，商业与金融）— 签字之前，先把不利条款找出来。扫描六类高风险条款，按六种谈判立场加权，输出结构化风险报告与谈判备忘。
- **风险评估矩阵**（`risk-assessment-matrix`，商业与金融）— 把风险从形容词变成可排序的决策项。完成风险识别、影响×概率评分、热力图、风险登记册、缓释策略与剩余风险跟踪。
- **投资风险量化引擎**（`investment-risk-engine`，商业与金融）— 用收益、回撤与组合指标检验投资判断。基于组合绩效与风险模型计算夏普比率、最大回撤、资产配置和组合优化，并生成 HTML 分析报告。
- **仓颉技能工坊**（`cangjie-skill`，知识与文档）— 把一本书蒸馏成一组可执行技能。将书籍、长视频、播客、课程或访谈中的框架、原则与方法论提取为原子化、可复用的技能。
- **结构化文档共创**（`doc-coauthoring`，知识与文档）— 先对齐读者，再写内容。通过上下文转移、分段迭代和读者测试，完成提案、技术规格、决策文档等结构化内容。
- **MarkItDown 文档转换**（`markitdown`，知识与文档）— 把多种格式统一成可检索的 Markdown。将 PDF、Office、图片、音频、网页、表格、压缩包和视频链接转换为 Markdown，保留结构信息。
- **PDF 全能工具箱**（`pdfkit-py`，知识与文档）— 五十条命令覆盖 PDF 全生命周期。以纯 Python 完成 PDF 阅读、编辑、转换、表单、加密、签名、OCR、书签、压缩和拆分合并。
- **微信读书助手**（`weread-skills`，知识与文档）— 把阅读痕迹整理成可用的知识笔记。搜索书籍、管理书架、读取划线和书评、查看阅读统计，并生成 Obsidian 知识笔记。
- **高级前端交付**（`frontend-dev`，软件工程）— 从界面、动效到文案的一次性交付。组合高级 UI、电影级动效、AI 素材与转化文案，完成落地页、营销站、产品页和数据看板。
- **单文件应用工程护栏**（`spa-engineering-guard`，软件工程）— 让单文件 HTML 应用也能工程化交付。为单文件 HTML 应用提供正则、选择器、存储隔离、题库校验、导航协议和按钮规范等护栏。
- **多模态桥接层**（`multimodal-bridge`，软件工程）— 为纯文本模型接上图像、视频和 3D 能力。提供 OCR、生图、图片搜索、3D/特效与视频理解五条桥接路径，按任务自动选择。
- **τ 全链路诊断**（`tau-diagnosis`，软件工程）— 定位智能体系统真正的时延与能力瓶颈。用 τ-minimization 方法做四层时延诊断、能力堆叠审计和复利闭环设计。
- **τ 增强诊断**（`tau-diagnosis-zcode`，软件工程）— 并行推理与交叉验证版全链路诊断。在标准 τ 诊断上叠加 S1–S4 并行推理、智能体分派、跨层验证和置信度量化。
- **创意策源引擎**（`creative-origin-engine`，内容与创意）— 让创意先经受攻击，再成为方案。三智能体并行提出建构、解构和数据锚定视角，经 Critic 与 Defender 交叉验证，输出二十分制策划案。
- **AI 绘本生产线**（`picture-book-pipeline`，内容与创意）— 从故事结构到版面一致性的完整流水线。覆盖七种作品类型、四种角色系统和五种版面模式，保持角色与风格一致性。
- **声明式视频生产线**（`video-production-pipeline`，内容与创意）— 用组件和参数复现视频生产。基于 Remotion 的声明式视频流程，覆盖参考拆解、脚本、组件、封面、BGM、多分辨率与质检。
- **BGM 智能搜索**（`pixabay-bgm-search`，内容与创意）— 从文案情绪找到合适的免费背景音乐。从视频标题、描述和字幕提取情绪、风格与节奏关键词，搜索 Pixabay/Freesound 并下载匹配音乐。
- **上下文清理协议**（`context-cleanup`，办公与协作）— 任务收尾时释放上下文，而不是一直背着它。在实质任务完成后识别可释放内容、移除冗余中间结果、压缩记忆写入，降低 token 与积分消耗。
- **浏览器自动化执行器**（`snap-up-assassin`，行业垂直）— 双通道、时钟校准与五层守护的自动化模板。面向合法授权的浏览器自动化场景，提供双通道并行、RTT 校准、拟人化点击、自适应轮询与容错守护。
